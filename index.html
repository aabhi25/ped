How the old text is removed
  • Only the words you change are rewritten. New text reuses the letter shapes already inside the file; if a character is not in the file, the same font family is used from a built-in set of common open fonts, and you are told when only a similar font was available.
  • Each edit deletes the original characters from the page’s content, then writes the new text at the same baseline, size and colour. Nothing is painted over the top, so there is no hidden layer to select, copy or search.
  • The download is a complete rewrite of the file. Earlier saved revisions and unused objects are dropped.
  • Your PDF is processed in this browser tab only. It is not uploaded anywhere, and Undo history is discarded when you close the tab.
  • Scanned pages are pictures, not text, so they have nothing to click.
  • Properties shows the file’s title, author, dates and the software that made it, and lets you change or remove them.
